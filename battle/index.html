Pokemon Arena

A private Pokemon Showdown server hosting a bot I'm training with poke-env. The server idles by default and wakes on your click — expect a 5–10 second warm-up on the first connection.

Play

Open the Showdown client, pick any username, and challenge arena-bot to a Random Battle.

Launch client → server sleeping

How it works

  • GitHub Pages

    Static landing page and a self-hosted pokemon-showdown-client build, both served from this site.

  • Fly.io Machine

    A 512MB container running pokemon-showdown --no-security plus a poke-env bot. Scales to zero after 5 minutes of no active battles.

  • Bot

    A poke-env Player subclass that accepts any open challenge. Current checkpoint is a baseline while training is in progress.

Caveats

  • --no-security means the bot's username is first-come; usernames aren't registered. Fine for a demo, not for leaderboards.

  • The server resets on every suspend. Replays and ratings don't persist.

  • If the warm-up takes longer than ~15 seconds, refresh — the machine may have been building cache from a cold image.

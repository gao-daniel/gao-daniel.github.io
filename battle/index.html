This is a private Pokémon Showdown server hosting a bot I’m training with poke-env. The server sleeps until someone visits. Expect a 5 to 10 second warm-up on the first connection.

Open the client, pick any username, and challenge arena-bot to a Random Battle.

Launch the client (server sleeping)

How it works

  • GitHub Pages serves this page and a self-hosted pokemon-showdown-client build.
  • A 512MB Fly.io machine runs pokemon-showdown --no-security plus the bot. It scales to zero after 5 minutes without an active battle.
  • The bot is a poke-env Player subclass that accepts any open challenge. The current checkpoint is a baseline while training continues.

Caveats

  • Usernames aren’t registered, so the bot’s name is first come, first served. That’s fine for a demo but not for leaderboards.
  • The server resets every time it suspends. Replays and ratings don’t persist.
  • If the warm-up takes longer than about 15 seconds, refresh. The machine may be starting from a cold image.
